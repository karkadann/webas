# webas — hosted page for screen-stream (web android stream)

GitHub Pages launcher for the **screen-stream** app, reached over WebTransport. Split out of the shared
`webstream` project so each app has its own page. Address: `3.3.3.1` (VPN/hotspot) or `webas.local` (mDNS).
The page loads the app page over the link; protocol and certs are the installed APK (shared `certs.js`).

Published on push to `master`: https://karkadann.github.io/webas/
